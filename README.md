# Python Data & APIs (Module 04)

A data analysis application built in Python that cleans and analyzes a dataset, visualizes it, pulls live weather data from a REST API, and generates a report.

## Features
- NumPy and Pandas data analysis (groupby, pivot tables, filtering)
- Data cleaning: duplicates, missing values, data types, renaming
- 8 visualizations with Matplotlib and Seaborn
- REST API consumption (Open-Meteo, Chennai weather) with JSON parsing
- Automated report generation (`analysis_report.txt`, CSV outputs)

## Tools
Python, NumPy, Pandas, Matplotlib, Seaborn, Requests, Google Colab

## How to run
1. Open `Python_APIS` in Google Colab
2. Runtime > Run all
3. Or locally: `pip install -r requirements.txt` then open the notebook in Jupyter
